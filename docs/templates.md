## PostgreSQL database

Restore a pg_dump into a throwaway PostgreSQL and check tables and row counts.

Verifies: data, database

**Back it up so it is restorable**

- Never back up a running PostgreSQL data directory with file tools; back up a dump instead: `pg_dump -U app app > /srv/app/db/dump.sql` right before `restic backup`.
- Make the backup job fail when pg_dump fails (set -e), so a stale dump is never backed up.

**Notes**

- Assertions are examples: an empty table is legitimate for some installs.

## Vaultwarden

Check the vault database, the JWT signing key, and optionally start Vaultwarden on the restored data.

Verifies: data, database, application · [upstream backup docs](https://github.com/dani-garcia/vaultwarden)

**Back it up so it is restorable**

- Back up the whole /data directory (db.sqlite3, rsa_key*, attachments, sends, config.json).
- Copying a live SQLite file can capture a torn database. Use `sqlite3 /data/db.sqlite3 ".backup '/data/db-backup.sqlite3'"` before the backup, or stop the container.

**Notes**

- Signups and invitations are disabled inside the test instance. It has no network access.
